The repo Import it

What this is

A card template for Anki, in plain HTML and CSS files you paste into a note type. The front and back layouts carry top and bottom bars, buttons, and a timer, and the styling is drawn to look right in the desktop app and in desktop and mobile browsers. The template was first posted on Reddit, then moved to this repo so people can find it in one place.

I keep this one in the fleet as the reference for how much a card face can change before it stops feeling like Anki. Answer: quite a lot, and the screenshots in the README prove it on both desktop and mobile.

Fields, bars, and the timer

  • Five fields: front, back, extra, tip, and source. Empty fields are not displayed, so there is no need to fill them all.
  • The first button in the upper left shows or hides the tip field. Next to it, a timer shows the time elapsed since the card was opened, and clicking it pauses it.
  • Honest limit, from the README: the timer button is not synchronized with Anki's own timer, so pausing one does not pause the other.
  • Tags render short: only the name after the last :: is shown, and underscores are treated as spaces.
  • The template does not change the top and bottom bar buttons in the desktop app, only in mobile and desktop browsers. The README author used the Beautify add-on for the desktop app buttons.
  • Mobile note from the README: it works on the iOS app. Android testing was still an open question in the README.

Importing

  1. Open Anki, click Add, select Note Type, click Manage, click Add, choose Add: Basic, and name the note type.
  2. Select the note type you created and click Cards.
  3. Paste the code from front.html in Front Template, and the code from back.html in Back Template. Both live in the HTML folder.
  4. Paste the code from one of the styles in the CSS folder into Styling, and click Save.
